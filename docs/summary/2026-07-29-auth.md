## Backend — Laravel API

| Endpoint | Method | Auth | What it does |
|---|---|---|---|
| `/api/login` | POST | guest | Validates email+password, returns `{ token, user }` |
| `/api/logout` | POST | sanctum | Revokes the current Bearer token |
| `/api/user` | GET | sanctum | Returns the authenticated user |

### Auth Flow
```
Login:  Form → fetch POST /api/login → store token in localStorage → success dialog
Logout: Click Sign Out → fetch POST /api/logout (revoke token) → clear localStorage
API:    authFetch('/api/...') auto-attaches Authorization: Bearer <token>
Admin:  /admin/login → session-based → is_admin = true required
```
