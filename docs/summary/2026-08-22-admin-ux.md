## Bugs found & fixed (with root cause)

1. **Collection-rate / unpaid-delta tests returned wrong numbers** — `Payment::factory()`
   auto-creates invoices that inflate "billed"; fixed by attaching payments to known
   invoices. `unpaidDelta` originally compared "this month vs same point last month"
   which double-counted future invoices; redefined to compare billing-period months.
2. **`contentFooter` on tables must return a `View`, not `HtmlString`** — the Filament
   blade calls `$contentFooter->with([...])`, which `HtmlString` lacks (PHP error on
   render). Fixed with a dedicated `footer-total` blade partial.
3. **`canDelete()` + `DeleteAction->before()` `$this->halt()` fails** — in a static
   resource context `$this` isn't a component; the `before` hook must accept the action
   as an injected parameter (`function (Actions\DeleteAction $action, Model $record)`)
   and call `$action->halt()`.
4. **`ResetPassword`/`RequestPasswordReset` `mount()`** — must call `parent::mount()`
   first (the base fills the form / handles redirect); the test failure (no notification)
   was a missing `parent::mount()` call.
5. **`ValidationException` key for a CreateRecord form** is `data.invoice_id` (not bare
   `invoice_id`) — matched Filament's state-path prefix after one test round-trip.
